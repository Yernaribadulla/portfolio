# YERNAR OS — реализация и запуск

Дата проверки: 16 октября 2026 года. Локальная ветка: `feat/yernar-os`.

## Что реализовано

- React + TypeScript + Vite с базовым путём `/portfolio/`.
- Настоящая 3D-сцена Three.js / React Three Fiber: трёхместный диван с общим каркасом и подлокотниками, оригинальная модель ноутбука, контактные тени, холодный свет, отражения и лёгкие слои тумана.
- Ноутбук доработан по визуальному референсу пользователя: тонкая скруглённая крышка, металлический корпус с фасками, узкая рамка, клавиатура с обозначениями и клавишами разной ширины, трекпад, решётки динамиков, шарниры, камера и боковые разъёмы. Изображение референса не включено в сайт.
- Одна GSAP timeline с ScrollTrigger управляет вступлением. Визуальная сцена всегда закреплена во viewport, включая конец scroll-диапазона, пока scrub завершает приближение. Это исключает проскакивание страницы и последующий возврат. Обратная прокрутка сохраняет открытые окна; отдельный флаг выхода предотвращает повторное защёлкивание при начале обратной анимации.
- Модель ноутбука создана и сохранена в Blender 5.2: `modeling/yernar-laptop.blend`, воспроизводящий скрипт `modeling/build_laptop.py`, рендер Cycles `modeling/laptop-preview.png`. Сайт загружает экспортированный Blender файл `public/models/laptop.glb`.
- Один и тот же React-интерфейс отображается на экране ноутбука и становится рабочим столом. Четыре угла экрана проецируются камерой в CSS `matrix3d`. До конца перехода интерфейс исключён из ввода через `inert`.
- Рабочий стол с семью приложениями, панелью запуска и окнами: открытие, закрытие, перемещение, фокус, порядок наложения, сворачивание и разворачивание.
- Окна «Обо мне», AI-Hunter, Outreach Agent, VoxBridge, «Штиль», «Контакты» и безопасная симуляция терминала. Команды: `help`, `about`, `projects`, `ls`, `contact`, `skills`, `whoami`, `pwd`, `date`, `history`, `open <имя>`, `clear`. Поддерживаются история ↑/↓, Tab, Ctrl+L, Ctrl+C и кнопки команд; Shift+Tab позволяет выйти из поля.
- Открытие, закрытие, сворачивание и разворачивание окон анимированы через GSAP; reduced-motion отключает основные переходы. Контактные кнопки в footer и dock открывают приложение с копированием email, ссылкой Gmail и обычным mailto.
- Часы читают часовой пояс устройства через Intl без принудительного часового пояса; время корректно и на экране ноутбука, и на рабочем столе. Проверены Europe/London и Asia/Tokyo.
- Металлические PBR-материалы корпуса и матового трекпада перенесены из Blender. У ткани уменьшена избыточная глянцевость, нормали и текстуры фильтруются с anisotropy. Туман состоит из пяти мягких слоёв с детерминированным перемещением от скролла.
- Русский интерфейс. Данные о проектах, опыте и контактах перенесены из исходного README без добавления вымышленных достижений.
- Мобильная раскладка, видимый клавиатурный фокус, `Escape` для закрытия окна, `Alt` + стрелки на заголовке для перемещения. Ссылки на проекты и демо.
- Единственная видимая кнопка входа — полупрозрачная «Пропустить интро» с мягкой анимацией тени. Она исчезает при приближении к экрану. Сохранены прямая ссылка `/portfolio/#desktop` и лёгкий режим `/portfolio/?lite=1`.
- При входе рабочий стол фиксируется: инерция и небольшой обратный жест не выводят из ноутбука. После паузы намеренный скролл вверх (90 px суммарного wheel delta) возвращает 3D; содержимое открытых окон прокручивается независимо. Поддержан обратный свайп, ArrowUp и PageUp вне элементов управления. Кнопка «Интро» возвращает в начало.
- Сглаживание WebGL дополнено повышенным разрешением рендера (DPR 1.75–2), ткань меньше рябит. Окружение затемнено, добавлен площадной свет экрана. Справа во вступлении — мягкое свечение, реагирующее на курсор.
- Иконки на широком рабочем столе закреплены в одной колонке, в том числе «Контакты». Поле терминала выделено рамкой, подсказкой и кнопкой Enter. Системные подписи увеличены и контрастнее; полосы прокрутки скрыты, сама прокрутка работает.
- При reduced-motion, отсутствии WebGL, сбое модели или загрузке дольше 20 секунд доступен рабочий стол. В этих случаях используется его статичный фон, а отдельное статичное вступление пропускается.
- 3D загружается отдельным JS-модулем. DPR ограничен 2; рендеринг по необходимости, одна карта теней 2048×2048, которая повторно используется при движении камеры, повторяющиеся части Blender-модели объединены по материалу. Нет тяжёлого volumetric raymarching.

## Локальный запуск

Требуется Node.js 24 и npm. Откройте терминал в каталоге этого репозитория:

```sh
npm ci
npm run dev
```

Адрес: `http://127.0.0.1:5173/portfolio/`.

```sh
npm run typecheck
npm run build
npm run preview
```

Проверка production-сборки: `http://127.0.0.1:4173/portfolio/`.

```sh
npx playwright install chromium
npm test
```

Тесты автоматически запускают dev-сервер, если на порту 5173 ещё нет сервера. При занятом порте убедитесь, что там запущен именно этот проект.

## GitHub Pages

1. Закоммитить изменения и отправить ветку в `Yernaribadulla/portfolio`, затем влить в `master` или `main`.
2. В репозитории открыть **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Workflow `Deploy YERNAR OS to Pages` выполняет `npm ci`, TypeScript-проверку, production build, загрузку артефакта `dist` и deployment. Его можно запустить вручную через Actions.
4. После успешного deployment сайт будет доступен по адресу `https://yernaribadulla.github.io/portfolio/`.

Публикация на GitHub в рамках этой локальной реализации не выполнялась. Указанный публичный адрес — ожидаемый адрес после деплоя, а не подтверждение опубликованной версии. Удалённый README не менялся.

## Технические ограничения и дальнейшая доводка

- Это realtime-визуализация. Фотореализм уровня исходного рекламного референса не подтверждён: для него полезны дополнительная работа с микрогеометрией, тканью, отражениями и постановкой света. Модель ноутбука создана в Blender, не является фотограмметрией.
- В 3D интерфейс рисуется в собственном соотношении сторон дисплея ноутбука, независимо от окна браузера. На последних 13% перехода проекция расширяется, а размер DOM и адаптивная раскладка пересчитываются. Это художественный выход из физической плоскости в браузер; шрифты и иконки не растягиваются из узкого viewport.
- Туман реализован экспоненциальным fog и прозрачными спрайтами; объёмного рассеивания света нет.
- Целевые 60 FPS не заявляются как измеренный результат. Нужен прогон на реальных устройствах со встроенной графикой и на мобильных GPU. Есть лёгкий режим и рендеринг по необходимости, но нет автоматического определения слабого GPU по бенчмарку.
- Браузерные тесты выполнены в Chromium. Safari, Firefox, реальные сенсорные устройства и скринридеры требуют отдельной проверки.
- Шрифты Golos Text и Manrope загружаются из Google Fonts; при недоступной сети используются системные sans-serif. Для полностью автономной поставки шрифты можно разместить локально с их OFL-лицензиями.
- GLB дивана около 3.1 MB с встроенными текстурами. Для более строгого мобильного бюджета следующий шаг — meshopt/KTX2 и проверка качества компрессии.
- Положение окон живёт в текущей сессии React; перезагрузка страницы его сбрасывает. Терминал не является настоящей оболочкой и ничего не отправляет во внешние сервисы.


## Уточнение света, ткани и движения окон

- Экран: площадной источник для отражений и локальный источник с собственной картой теней. Общий студийный свет приглушён; контактная тень на полу усиливает посадку дивана.
- Для теней используются две карты 2048×2048, прогреваемые после загрузки геометрии и затем переиспользуемые. Положение источников статично.
- Средняя подушка деформируется под основанием ноутбука: максимальное углубление 14 мм с плавным спадом; ноутбук и привязанная к нему проекция экрана опущены на 11 мм.
- Обивка серо-оливковая, с процедурным плетением, исходной картой нормалей и слабым мягким sheen. Каркас и подлокотники используют ту же ткань.
- Разворачивание окна использует снимок прямоугольника до изменения DOM (`getSnapshotBeforeUpdate`). FLIP-анимация длится 0.8 с; восстановление проходит обратным растяжением. Reduced-motion выключает переход.
- Добавлен Playwright-сценарий, проверяющий несколько промежуточных размеров при разворачивании и восстановлении окна.

## Интерактивный AI-сгусток

- Движение мыши оставляет локальную борозду и мягкую волну на передней поверхности. Сила зависит от скорости движения; деформация затухает за 1.6 с.
- Быстрые пересечения интерполируются между событиями мыши. История ограничена 32 точками; после восстановления формы пересчёт геометрии останавливается.
- Сенсорная прокрутка не перехватывается. При reduced-motion интро отключено; обработчик также проверяет эту настройку перед реакцией.
- Туман плавно исчезает у пола до пересечения с его геометрией. Общий свет затемнён; локальная подсветка экрана сохранена.
