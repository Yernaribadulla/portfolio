# YERNAR OS / ORBITAL EDITION

Портфолио и EVENT HORIZON объединены в одно React-приложение, в репозитории `Yernaribadulla/portfolio`. Отдельных iframe, второго сервера или переходов между двумя сайтами нет.

## Как устроен сайт

- **Портфолио:** живая чёрная дыра, четыре исходных проекта, «Обо мне», контакты, терминал, оконный интерфейс и Sparxie.
- **Обсерватория:** та же WebGL-сцена, пять глав, свободная орбита, линзирование, плазма, шесть параметров, пауза, качество LOW/HIGH/CINEMATIC, адаптивный DPR и процедурное аудио. Окна портфолио и история терминала сохраняются при переходе туда и обратно.
- **Студия:** сохранённая 3D-комната с ноутбуком и исходным вступлением. Она загружается по требованию. При входе в студию обсерватория освобождает renderer, render targets, геометрии, материалы и WebGL-контекст. Возврат из студии открывает новый рабочий стол.

Главный экран использует спокойный ракурс и стандартную эмиссию. Параметры, выбранные в обсерватории, сохраняются в памяти текущей вкладки. Звук выключается при выходе из неё. Параметры и окна не сохраняются после перезагрузки страницы.

## Маршруты и запуск

```sh
npm ci
npm run dev -- --port 5180
npm run build
npm run preview -- --port 4180
```

База URL — `/portfolio/`. Маршруты используют hash, поэтому работают на GitHub Pages без серверных rewrite-правил.

| Адрес после `/portfolio/` | Режим |
| --- | --- |
| пустой или `#desktop` | Орбитальное портфолио |
| `#observatory/1` … `#observatory/5` | Нужная глава обсерватории |
| `#studio` | Исходное кинематографическое вступление |
| `#studio/desktop` | Рабочий стол внутри студийного опыта |
| `?lite=1#studio` | Студия без 3D-вступления |

`npm run build:pages` обновляет `docs/`. Конфигурация существующего GitHub Pages использует `master:/docs`; публикация новой версии произойдёт после попадания сборки в `master`.

## Архитектура

- `src/OrbitalApp.tsx` — маршруты, общий графический слой, переключение режимов и фокус.
- `src/desktop/` и `src/data/projects.ts` — исходное содержимое портфолио и окна.
- `src/horizon/` — оригинальная симуляция, GLSL, Zustand и Web Audio.
- `src/Studio.tsx`, `src/scene/` — прежнее вступление.
- `src/styles/global.css` ограничен областью `.legacy-ui`, стили обсерватории — `.horizon-root`, через CSS `@scope`. Общая композиция — `src/styles/orbital.css`.

Обсерватория и студия загружаются отдельными модулями. Между портфолио и обсерваторией canvas сохраняется. Three.js использует одну версию для обоих модулей. Шрифты включены локально, запросов к Google Fonts больше нет.

## Проверка, 21 октября 2026

- TypeScript и production build прошли; отдельно собрана версия `docs/` под реальную базу GitHub Pages.
- Все 7 численных тестов геодезических прошли (`npm run test:physics`).
- В браузере проверены проекты, контакты, запуск `open event-horizon` в терминале, сохранение окон/истории, пять глав, параметры, пауза и переключение звука.
- При паузе `data-time` оставалось `97.676` во время смены глав. Изменение массы и spin было подтверждено значениями shader uniforms.
- Проверены компоновки 390×844, 721×717 и 1440×900. Исправлены пересечения стилей, отступ графического слоя и размеры мобильных окон.
- На RTX 4050 Laptop в локальном Chromium в проверенных сценариях HIGH наблюдалось примерно 135–144 FPS, GPU около 2.8–3.9 ms. Это короткое наблюдение в данной среде, не гарантия длительной производительности или результата на других устройствах.
- Сохранённая студия загрузила сцену и выполнила переход на рабочий стол. Ошибок выполнения JavaScript и ошибок компиляции основного shader не обнаружено. При компиляции материалов исходной студии драйвер ANGLE выдаёт предупреждения о точности чисел; рендер продолжает работать.
- Во время интеграции исправлена ошибка удаления DOM при выходе из закреплённой GSAP-сцены: очистка перенесена в layout effect, студия получила собственный DOM-контейнер. Повторный production-прогон «студия → ноутбук → орбита» завершился без новых ошибок; остаточных `.pin-spacer` нет, в обсерватории один WebGL-canvas и 13 текстур.
- Добавлены пять сценариев Playwright в `tests/orbital.spec.ts`, старые сценарии направлены на студийные маршруты. Полный автоматический Playwright-прогон в этой сессии не выполнялся; проверки интерфейса проводились через управляемый браузер.

## Ограничения

Нужен современный браузер с WebGL 2 и CSS `@scope`; Safari и физические мобильные устройства в этой сессии не проверялись. При отказе WebGL содержимое портфолио остаётся доступным, обсерватория показывает сообщение и возврат. Субъективное звучание аудио и длительная тепловая нагрузка не оценивались.

Лучи используют численную модель Шварцшильда. Spin влияет на плазму и эмиссию, но не реализует метрику Керра. BEYOND — явно обозначенная художественная гипотеза. Подробности модели доступны через **The model** в обсерватории; первоисточники: https://arxiv.org/abs/1103.0585 и https://ebruneton.github.io/black_hole_shader/.
